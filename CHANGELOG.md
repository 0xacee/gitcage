# Changelog

All notable changes to GitCage are documented here. The project follows Semantic
Versioning after the initial pre-1.0 releases.

## [0.1.0] - 2026-09-01

### Added

- Named Debian WSL2 cages with isolated virtual disks.
- GitHub device authentication and recorded identity binding.
- GitHub repository cloning through cage-owned credentials.
- Loopback-only password-protected code-server IDE.
- Direct command execution, status, list, open, and stop commands.
- Fifteen-check runtime isolation audit.
- Pester, PSScriptAnalyzer, Bash, and credential-pattern CI.
- Threat model, architecture, roadmap, security, and contribution documentation.
